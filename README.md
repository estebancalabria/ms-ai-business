# ms-ai-business

Repositorio de estudio y soporte para cursos Microsoft AI orientados a negocio, productividad y transformacion organizacional.

Incluye material para:

- AI-901: Azure AI Fundamentals
- AB-730: Transform business workflows with generative AI
- AB-731: AI Transformation Leader

Este repo funciona como base de trabajo para clases, workshops y preparacion de certificaciones.

## Que vas a encontrar

- Apuntes por curso y modulo
- Laboratorios guiados
- Recursos de referencia y links utiles
- Material para workshops corporativos
- Notas de estrategia, adopcion y casos de uso

### AI-901

- Labs y scripts de apoyo

### AB-730

Ruta orientada a productividad con Copilot y flujos empresariales:

- Generative AI para trabajo diario

- Labs practicos por escenario

Ruta enfocada en liderazgo y transformacion con IA:

Entrada recomendada: [AB-731/Readme.md](AB-731/Readme.md)
