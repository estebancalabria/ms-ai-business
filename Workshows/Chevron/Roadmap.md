### 4. Casos Reales de Uso

#### 🏷️ Caso 1 — Área Comercial

| | |
|--|--|
| **Problema** | Los vendedores pierden tiempo buscando información; dificultad para resumir reuniones y preparar propuestas |
| **Solución** | Microsoft Copilot — búsqueda sobre documentos, mails y reuniones |
| **Beneficio** | Menos tiempo administrativo · Mejor preparación comercial · Mayor productividad |

#### 👥 Caso 2 — RRHH

| | |
|--|--|
| **Problema** | Muchas consultas internas repetitivas; sobrecarga del equipo de RRHH |
| **Solución** | Agente interno con Copilot Studio |
| **Beneficio** | Menos tickets internos · Respuestas más rápidas · Mejor experiencia del empleado |

#### 💰 Caso 3 — Finanzas

| | |
|--|--|
| **Problema** | Procesamiento manual de facturas; errores en carga de datos |
| **Solución** | OCR + IA + automatización |
| **Beneficio** | Reducción de errores · Procesamiento más rápido · Menor trabajo manual |

#### 📈 Caso 4 — Predicción de Demanda y Ventas

| | |
|--|--|
| **Problema** | Dificultad para prever ventas futuras; exceso o falta de stock; decisiones basadas únicamente en experiencia manual |
| **Solución** | Machine Learning con Azure ML — modelos predictivos sobre datos históricos, análisis de tendencias y comportamiento |
| **Beneficio** | Mejor planificación · Reducción de sobrestock o faltantes · Decisiones basadas en datos · Optimización operativa |

#### Asistentes vs. Agentes

| | Asistentes | Agentes |
|--|------------|---------|
| **Qué hacen** | Responden consultas, ayudan al usuario, generan contenido | Ejecutan tareas y procesos, interactúan con datos y sistemas |
| **Ejemplos** | Microsoft Copilot, GitHub Copilot | Agentes de Copilot Studio, Agentes de Azure |

#### Anatomía de un agente

- System Prompt
- Conocimiento y contexto (RAG)
- Herramientas y acciones
- Memoria y flujo de trabajo
- Interacción con sistemas empresariales

## 🔁 Bloque Transversal: Responsible AI

> Presente a lo largo de toda la clase · Alineado a AB-731 - AI-900

| Principio | Descripción |
|-----------|-------------|
| **Fairness** | Equidad en los resultados del modelo |
| **Transparencia** | Explicabilidad de las decisiones de IA |
| **Privacidad y seguridad** | Protección de datos en todos los niveles |
| **Confiabilidad** | Comportamiento predecible y robusto |
| **Sesgos** | Identificación y mitigación de sesgos |

**Oportunidades y desafíos:**
- Respuestas incorrectas o fabricadas (alucinaciones)
- Gestión de expectativas en usuarios no técnicos
